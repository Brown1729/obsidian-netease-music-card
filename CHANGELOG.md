# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-08

### Added

- Paste a NetEase Cloud Music song link to turn it into a card with title, artist, album and cover.
- Support for full song URLs, mobile URLs, path-style URLs and `163cn.tv` short links.
- Automatic cleanup of NetEase App share text.
- Optional local cover download with reuse of already downloaded files.
- Callout and plain Markdown card styles.
- Commands, editor context menu and ribbon icon for inserting songs.
- Command for converting selected NetEase links into cards.
- Settings for cover storage, cover width, album display, original link display and share text cleanup.
